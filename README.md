# SEA.AI Customer Document Library

This repository contains official customer documentation for SEA.AI products.

SEA.AI makes machine vision systems for vessels. The systems use thermal and
optical cameras with AI to detect objects on the water. They act as a
collision avoidance assistant for the crew.

## What you find here

| Folder | Content |
|---|---|
| `sentry/` | Sentry user manual, installation guide, release notes |
| `watchkeeper/` | Watchkeeper user manual, installation guide, release notes |
| `brain/` | Brain user manual, integration guide |
| `offshore/` | Offshore user manual, installation guide |
| `competition/` | Competition user manual |

## How to use this library

1. Open the folder for your product.
2. Find the document for your software version.
3. Download the PDF or read it in the browser.
